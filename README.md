## 🎨 Design Philosophy & Themes / 设计哲学与主题

### 1. Collective Unconscious / 集体潜意识
Jung famously proposed that beneath our individual minds lies a shared, inherited psychic ocean. We are like separate islands on the surface, but connected to the same continent in the deep abyss.
荣格提出，在个人意识之下，存在着人类共享的、由原型构成的潜意识海洋。在物理世界的表层我们是孤立的岛屿，但在深海之中我们扎根于同一片相连的大陆。

### 2. Telepathic Resonance / 心灵感应共鸣
Telepathy is not a mystical radio transmission; it is the synchronous awakening of multiple minds touching the same subconscious root. When a ripple waves from one mind, it triggers echo patterns in others across space and time.
心灵感应并非超自然的无线电波，而是多个主体沉降到同一潜意识根系时产生的非定域共鸣。彼处思绪的泛起，将跨越时空在此时此刻激起涟漪。

## 💫 Core Animations & Interactive Physics / 核心交互与动画物理

* **Liquid Flow Field (液态暗流场)**: Particles drift along fluid wave vectors generated by sine/cosine algorithms, resembling ocean micro-organisms or moving thoughts.
* **Unseen Others (匿名他者)**: Three distinct colored virtual nodes roam the background representing "other minds" in the shared collective unconscious.
* **Bilateral Telepathic Bridge (双向感应光桥)**: When you (mouse cursor) get close to another mind, a luminous energy bridge connects you. High-frequency Anime.js light pulses stream in both directions.
* **Echo Ripple Interference (多重干涉涟漪)**: Clicking on the screen sends a primary wave. As it passes through other minds, it triggers Cyn-colored secondary "Echo Ripples," causing waves to interfere and particles to illuminate.
* **Jungian Archetypes Morphing (荣格四大心理原型变换)**: Hovering over cards triggers smooth Anime.js transitions that morph the chaotic particle cloud into geometric representations:
  - **Persona (人格面具)**: Concentric circles splitting public mask from the inner self.
  - **Shadow (阴影)**: A gravity vortex drawing particles downward into a chaotic dark-red vortex.
  - **Anima/Animus (阿尼玛/阿尼姆斯)**: A double-helix wave traveling in opposite directions.
  - **Self (自性)**: A harmonious mandala matrix rotating in perfect order.

## 🛠️ Tech Stack / 技术栈

* **Frontend Framework**: Svelte 5 (with runes `$state`, `onMount`)
* **Animation Engine**: Anime.js v4.x (Modular ESM syntax, `animate`, `createTimeline`, `stagger`)
* **Styling**: Vanilla CSS (CSS variables, Custom blur grids)
* **Hosting Platform**: Cloudflare Workers (Assets binding) / Pages

## 💻 Local Development / 本地开发

### Installation / 安装
```bash
npm install
```

### Run Dev Server / 运行开发环境
```bash
npm run dev
```

### Build for Production / 生产构建
```bash
npm run build
```
*(Build is optimized to compile offline, omitting online schemas checks).*

### Preview Locally / 本地预览
```bash
npm run preview
```

## 🚀 Cloudflare Deployment / Cloudflare 部署

Deploying to your own Cloudflare edge node is simple using Wrangler:
```bash
# Generate worker types (required)
npx wrangler types

# Deploy to Cloudflare
npx wrangler deploy
```
